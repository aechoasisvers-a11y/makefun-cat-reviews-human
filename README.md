A one-star review written by a house cat about the human who squats in its sunbeam and types on its warm laptop all day.

## Entry

> One star. He sits in my sunbeam all day, types on my warm laptop, and gets paid for it.

## Run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
